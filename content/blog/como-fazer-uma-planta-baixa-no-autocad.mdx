# Como fazer uma planta baixa no AutoCAD: passo a passo completo

Se você precisa criar uma **planta baixa no AutoCAD**, provavelmente já percebeu que o programa oferece uma quantidade enorme de ferramentas.

São comandos, layers, blocos, cotas, linhas, polilinhas, hachuras, textos e várias outras funções.

Para quem está começando, isso pode parecer complicado.

Mas existe uma forma muito mais simples de entender o processo:

> **Uma planta baixa é construída por etapas.**

Você não precisa aprender todas as ferramentas do AutoCAD de uma vez. Primeiro, precisa entender a lógica do desenho. Depois, aprender os comandos que realmente fazem parte do seu fluxo de trabalho.

Neste guia, você vai aprender **como fazer uma planta baixa no AutoCAD desde o início**, passando pela preparação do arquivo, criação das paredes, portas e janelas, organização com layers, cotagem e finalização do desenho.

E, ao longo do artigo, também vamos mostrar alguns pontos importantes que costumam fazer diferença para quem deseja sair do nível iniciante e começar a trabalhar profissionalmente com AutoCAD.

---

## O que é uma planta baixa?

Antes de abrir o AutoCAD, vale entender exatamente o que estamos tentando representar.

A **planta baixa** é uma representação gráfica de um ambiente ou edificação vista de cima, normalmente considerando um plano horizontal de corte.

Ela permite representar elementos como:

- paredes;
- portas;
- janelas;
- ambientes;
- corredores;
- escadas;
- mobiliário;
- equipamentos;
- cotas;
- níveis;
- textos;
- áreas;
- informações técnicas.

Em um projeto arquitetônico, por exemplo, a planta baixa permite compreender a distribuição dos espaços.

Imagine uma residência.

Você pode ter:

- sala;
- cozinha;
- banheiro;
- dois quartos;
- área de serviço;
- garagem.

A planta baixa organiza visualmente esses ambientes e mostra como eles se relacionam.

É justamente por isso que aprender a criar uma planta baixa é uma das habilidades fundamentais para quem está começando a estudar **AutoCAD 2D**.

---

## É possível fazer uma planta baixa no AutoCAD sendo iniciante?

Sim.

E essa é uma das coisas mais importantes para entender antes de começar.

Você não precisa ser especialista em AutoCAD para criar uma planta baixa simples.

O que você precisa é compreender:

1. como trabalhar com medidas;
2. como utilizar coordenadas;
3. como desenhar linhas;
4. como criar paredes;
5. como utilizar layers;
6. como inserir portas e janelas;
7. como utilizar textos;
8. como adicionar cotas;
9. como organizar o desenho.

Depois que você entende esse processo, os comandos começam a fazer muito mais sentido.

O problema de muitos iniciantes é tentar decorar dezenas de comandos antes de entender **para que cada ferramenta serve**.

Aqui vamos fazer o contrário.

Primeiro vamos entender o processo.

# O que você precisa para começar

Para acompanhar este tutorial, você precisa basicamente de:

- AutoCAD instalado;
- computador;
- medidas do ambiente que deseja desenhar;
- conhecimento básico de navegação no programa.

Não precisa começar com uma planta enorme.

Na verdade, é melhor começar com uma planta pequena.

Por exemplo:

**Uma residência de 8 metros × 10 metros.**

Dentro dela podemos imaginar:

- sala;
- cozinha;
- banheiro;
- dois quartos.

A partir de uma planta simples, você consegue aprender praticamente todo o fluxo básico.

---

# 1. Comece pensando nas medidas

Um dos primeiros conceitos que você precisa dominar no AutoCAD é:

**desenhe utilizando medidas reais.**

Se uma parede possui 5 metros, você precisa representar essa dimensão corretamente no desenho.

Uma das vantagens do AutoCAD é justamente trabalhar com precisão.

Em vez de desenhar uma parede "mais ou menos daquele tamanho", você informa a medida.

Por exemplo:

```text
5 metros
```

ou, dependendo da unidade adotada no projeto:

```text
5000 mm
```

O importante é manter uma unidade consistente durante todo o desenho.

---

# 2. Crie um novo desenho

Abra o AutoCAD e crie um novo arquivo.

Antes de sair desenhando, é importante preparar o ambiente.

Uma boa prática é configurar:

- unidades;
- layers;
- limites e organização do desenho;
- estilo de cotas;
- estilo de textos.

Isso parece uma etapa pequena.

Mas existe um motivo para não ignorá-la.

Quanto mais organizado estiver o arquivo desde o início, mais fácil será trabalhar nele depois.

---

# 3. Configure as unidades

Para projetos arquitetônicos, é muito comum trabalhar com medidas em metros ou milímetros.

O importante é escolher uma unidade e manter o padrão.

No AutoCAD, você pode utilizar o comando:

```text
UNITS
```

Depois, configure o tipo de unidade de acordo com o projeto.

Por exemplo:

```text
Decimal
```

A precisão pode ser ajustada conforme a necessidade do desenho.

### Por que isso é importante?

Imagine desenhar uma parede de 5 metros e depois descobrir que o desenho inteiro está em uma escala diferente.

Você pode acabar tendo problemas com:

- cotas;
- blocos;
- impressão;
- áreas;
- detalhes;
- escalas.

Por isso, vale organizar as unidades logo no começo.

---

# 4. Crie os Layers

Agora chegamos a uma das partes mais importantes da organização de uma planta baixa.

Os **Layers**.

Se você colocar absolutamente tudo no mesmo layer, seu projeto pode rapidamente se tornar difícil de editar.

Imagine uma planta contendo:

- paredes;
- portas;
- janelas;
- cotas;
- textos;
- móveis;
- hachuras.

Agora imagine precisar esconder somente as cotas.

Se tudo estiver no mesmo layer, isso se torna muito mais trabalhoso.

Por isso, podemos criar layers separados.

Uma estrutura simples poderia ser:

| Layer      | Utilização          |
| ---------- | ------------------- |
| PAREDES    | Paredes da planta   |
| PORTAS     | Portas              |
| JANELAS    | Janelas             |
| COTAS      | Dimensionamento     |
| TEXTOS     | Textos              |
| MOBILIARIO | Móveis              |
| HACHURAS   | Hachuras            |
| EIXOS      | Eixos e referências |

Essa organização deixa o projeto muito mais fácil de controlar.

---

# 5. Comece desenhando a estrutura da planta

Agora vamos começar a construir nossa planta.

Imagine uma residência retangular.

Por exemplo:

**8 metros de largura × 10 metros de comprimento.**

Podemos começar criando o contorno externo.

O comando mais básico para isso é:

```text
LINE
```

ou simplesmente:

```text
L
```

No AutoCAD, muitos comandos possuem atalhos.

Isso é extremamente útil porque, conforme você ganha experiência, consegue trabalhar muito mais rapidamente.

---

# 6. Utilize coordenadas

Uma das grandes vantagens do AutoCAD é a precisão proporcionada pelas coordenadas.

Você pode informar exatamente onde deseja posicionar um ponto.

Por exemplo:

```text
0,0
```

representa uma coordenada inicial.

Depois, você pode informar outra posição.

Por exemplo:

```text
8,0
```

Isso permite criar uma linha horizontal de 8 unidades.

Depois:

```text
8,10
```

E então:

```text
0,10
```

Finalmente:

```text
0,0
```

Você terá criado um retângulo.

Outra maneira muito prática de trabalhar é utilizar coordenadas relativas.

Por exemplo:

```text
@8,0
```

significa deslocar 8 unidades na horizontal.

Depois:

```text
@0,10
```

significa deslocar 10 unidades na vertical.

Esse conceito se torna extremamente importante conforme você começa a trabalhar com projetos maiores.

---

# 7. Crie a espessura das paredes

Agora temos apenas o contorno.

Mas uma parede não é uma simples linha.

Ela possui espessura.

Uma das ferramentas mais úteis para isso é:

```text
OFFSET
```

Atalho:

```text
O
```

O Offset permite criar uma cópia paralela de um objeto a uma distância determinada.

Por exemplo:

```text
0.15
```

pode representar uma parede de 15 cm, dependendo da unidade utilizada no desenho.

Você seleciona a linha e informa a distância.

O AutoCAD cria uma linha paralela.

Esse conceito é fundamental para construção de paredes.

---

# 8. Divida os ambientes

Agora podemos começar a criar a distribuição interna.

Imagine que nossa residência possui:

- sala;
- cozinha;
- banheiro;
- quarto 1;
- quarto 2.

As divisórias internas podem ser criadas utilizando linhas ou polilinhas e, posteriormente, ajustadas com Offset.

Aqui entra uma habilidade importante:

**pensar no projeto antes de desenhar.**

Não saia simplesmente colocando linhas.

Pergunte:

- Qual será o tamanho de cada ambiente?
- Onde ficará a circulação?
- Onde estarão as portas?
- Qual será a posição das janelas?
- Os ambientes possuem espaço suficiente?

Uma planta baixa não é apenas um conjunto de linhas.

Ela representa uma organização espacial.

---

# 9. Use o TRIM para limpar o desenho

Durante a construção da planta, várias linhas podem ficar sobrando.

É aqui que entra outro comando fundamental:

```text
TRIM
```

Atalho:

```text
TR
```

O Trim permite cortar partes desnecessárias dos objetos.

Imagine duas paredes se cruzando.

Talvez uma parte da linha precise ser removida para criar uma abertura.

Em vez de apagar e redesenhar tudo, você pode utilizar o Trim.

Esse é um daqueles comandos que você começa a utilizar constantemente depois que aprende.

---

# 10. Utilize EXTEND quando necessário

O comando:

```text
EXTEND
```

faz praticamente o movimento contrário.

Enquanto o Trim serve para cortar objetos, o Extend permite estender um objeto até determinado limite.

Atalho:

```text
EX
```

No trabalho com plantas, os dois comandos aparecem frequentemente.

Um fluxo bastante comum é:

```text
OFFSET → TRIM → EXTEND
```

Você cria a geometria, ajusta as interseções e limpa os excessos.

---

# 11. Crie as portas

Depois das paredes, chegou a hora de adicionar as portas.

Uma porta normalmente precisa representar:

- folha da porta;
- abertura;
- sentido de abertura;
- vão.

Você pode criar uma porta manualmente ou utilizar um bloco.

### O que é um bloco no AutoCAD?

Um bloco é um conjunto de objetos agrupados como uma única referência.

Por exemplo, uma porta pode ser transformada em um bloco.

Assim, em vez de desenhar a mesma porta repetidamente, você pode reutilizá-la.

Isso economiza bastante tempo.

---

# 12. Entenda o sentido de abertura

Não basta colocar um retângulo representando uma porta.

Em desenhos técnicos, é importante representar o sentido de abertura.

Normalmente utilizamos um arco para mostrar o movimento da folha.

Isso permite interpretar rapidamente:

**para que lado a porta abre?**

Esse detalhe pode parecer pequeno.

Mas é exatamente esse tipo de informação que faz uma planta deixar de parecer apenas um desenho e passar a funcionar como representação técnica.

---

# 13. Adicione as janelas

O mesmo raciocínio vale para as janelas.

Você pode criar um modelo padrão de janela e transformá-lo em bloco.

Depois basta inserir o bloco nos locais necessários.

Dependendo do projeto, podemos ter diferentes tipos:

- janela de correr;
- janela basculante;
- janela de abrir;
- janela grande;
- janela pequena.

O importante é utilizar uma representação consistente.

---

# 14. Insira os ambientes

Agora precisamos identificar cada cômodo.

Você pode utilizar o comando:

```text
TEXT
```

ou:

```text
MTEXT
```

para inserir textos.

Por exemplo:

```text
SALA
```

```text
COZINHA
```

```text
QUARTO 01
```

```text
BANHEIRO
```

Além do nome, também podemos indicar a área.

Por exemplo:

```text
SALA
18,50 m²
```

Isso facilita a leitura da planta.

---

# 15. Crie as cotas

Chegamos a outra etapa fundamental:

**dimensionar a planta.**

As cotas informam as medidas.

Sem elas, uma planta pode ficar muito mais difícil de interpretar.

Dependendo da versão e configuração do AutoCAD, você pode utilizar comandos como:

```text
DIM
```

para criar dimensões.

As cotas podem indicar:

- largura total;
- comprimento total;
- largura dos ambientes;
- tamanho de portas;
- tamanho de janelas;
- distâncias entre elementos.

---

# 16. Organize as cotas

Um erro comum de quem está começando é colocar as cotas de qualquer maneira.

O resultado pode ficar visualmente confuso.

Uma boa organização normalmente separa as informações.

Por exemplo:

### Cotas externas

Mostram as dimensões gerais da construção.

### Cotas intermediárias

Mostram divisões e posições.

### Cotas internas

Mostram dimensões específicas dos ambientes.

A organização das cotas facilita muito a leitura.

---

# 17. Utilize o OSNAP

Se existe uma ferramenta que você precisa aprender cedo no AutoCAD, é o:

```text
OSNAP
```

O Object Snap permite encontrar pontos específicos dos objetos.

Por exemplo:

- Endpoint;
- Midpoint;
- Center;
- Intersection;
- Perpendicular;
- Nearest.

Imagine que você precisa começar uma linha exatamente no final de outra.

Em vez de clicar aproximadamente, o OSNAP permite capturar o ponto correto.

Isso aumenta muito a precisão do desenho.

---

# 18. Utilize o ORTHO

Outro recurso muito importante é:

```text
ORTHO
```

Normalmente associado à tecla:

```text
F8
```

Quando ativado, ele restringe o movimento para determinadas direções, como horizontal e vertical.

Isso é especialmente útil em plantas baixas.

Grande parte das paredes possui linhas horizontais ou verticais.

Então o Ortho pode facilitar bastante a construção.

---

# 19. Hachuras

Dependendo do objetivo do desenho, também podemos utilizar hachuras.

O comando é:

```text
HATCH
```

As hachuras podem representar determinados materiais ou áreas.

Por exemplo:

- concreto;
- alvenaria;
- pisos;
- áreas específicas;
- materiais de acabamento.

É importante lembrar que a utilização de hachuras deve seguir o padrão adotado no projeto.

---

# 20. Revise a planta

Antes de considerar a planta concluída, faça uma revisão.

Confira:

### Medidas

As dimensões estão corretas?

### Paredes

Existe alguma parede incompleta?

### Portas

Todas possuem abertura e posicionamento adequado?

### Janelas

Estão corretamente posicionadas?

### Textos

Os nomes dos ambientes estão legíveis?

### Cotas

As dimensões estão organizadas?

### Layers

Cada elemento está no layer correspondente?

Essa revisão pode evitar problemas posteriores.

---

# 21. Configure a impressão

Fazer o desenho é apenas uma parte do trabalho.

Você também precisa saber preparar o arquivo para apresentação ou impressão.

No AutoCAD, existem diferentes conceitos relacionados à visualização e impressão, como:

- Model Space;
- Layout;
- Viewport;
- escala;
- configuração de página.

É nesse momento que muita gente percebe que **desenhar no AutoCAD e preparar um projeto profissional são habilidades diferentes, embora relacionadas**.

---

# Model Space x Layout

No **Model Space**, normalmente trabalhamos com o desenho em tamanho real.

No **Layout**, podemos preparar a apresentação do projeto para impressão.

Por exemplo:

```text
A4
A3
A2
A1
```

Podemos configurar:

- tamanho do papel;
- orientação;
- escala;
- viewport;
- impressão;
- penas;
- margens.

Aprender esse fluxo é muito importante para quem pretende utilizar o AutoCAD profissionalmente.

# O que mais dificulta quem está começando no AutoCAD?

Normalmente não é apenas o número de comandos.

Um dos maiores desafios é entender **como combinar as ferramentas**.

Por exemplo:

Você pode saber utilizar o Offset.

Pode saber utilizar o Trim.

Pode saber utilizar o Move.

Pode saber utilizar o Copy.

Mas isso não significa automaticamente que você saiba criar uma planta completa.

A habilidade aparece quando você consegue combinar essas ferramentas dentro de um fluxo.

Por exemplo:

```text
LINE
↓
OFFSET
↓
TRIM
↓
EXTEND
↓
BLOCK
↓
COPY
↓
DIM
```

Esse raciocínio é muito mais importante do que simplesmente decorar atalhos.
