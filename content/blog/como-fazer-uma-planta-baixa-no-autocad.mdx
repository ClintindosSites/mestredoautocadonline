## Como Fazer uma Planta Baixa no AutoCAD?

![Projeto de planta baixa residencial desenvolvido no AutoCAD](/images/blog/planta-baixa-autocad/planta-baixa-autocad.webp)
Já imaginou transformar uma ideia em uma planta baixa detalhada, com paredes, portas, janelas e medidas precisas?

É exatamente esse tipo de trabalho que o AutoCAD permite desenvolver. O programa é uma das ferramentas mais utilizadas para criação de desenhos técnicos e projetos nas áreas de arquitetura, engenharia e construção civil.

Mas, para quem está começando, surge uma dúvida: como sair de uma tela cheia de ferramentas e conseguir criar um projeto de verdade?

### O que você precisa aprender para criar uma planta baixa?

![Ferramentas do AutoCAD utilizadas na criação de uma planta baixa](/images/blog/planta-baixa-autocad/ferramentas-planta-baixa.webp)

Desenvolver uma planta baixa no AutoCAD exige mais do que simplesmente desenhar linhas. É necessário conhecer ferramentas que permitem criar medidas, organizar elementos e modificar o projeto com precisão.

Entre os recursos mais utilizados estão:

- **LINE e OFFSET:** para criar linhas e paredes.
- **TRIM e EXTEND:** para ajustar os elementos do desenho.
- **BLOCK:** para reutilizar portas, janelas e outros objetos.
- **LAYERS:** para organizar as informações do projeto.
- **DIM:** para inserir medidas e dimensões.

Quando você aprende a combinar essas ferramentas, começa a perceber como é possível transformar desenhos simples em projetos técnicos muito mais completos.
