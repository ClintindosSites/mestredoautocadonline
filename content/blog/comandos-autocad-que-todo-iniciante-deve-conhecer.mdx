## 1. LINE — Criar linhas

O comando **LINE** é um dos comandos mais importantes para quem está começando no AutoCAD. Ele permite criar uma linha reta entre dois pontos definidos pelo usuário.

É um comando utilizado constantemente em **plantas baixas, desenhos técnicos, projetos arquitetônicos e desenhos de engenharia**.

### Como usar o comando LINE

Na linha de comando do AutoCAD, digite:

```text
LINE
```

Depois pressione **Enter**.

O AutoCAD solicitará o primeiro ponto. Clique no local desejado ou informe uma coordenada.

Em seguida, indique o segundo ponto para definir o comprimento e a direção da linha.

### Atalho do LINE

Para trabalhar mais rapidamente, você também pode utilizar o atalho:

```text
L
```

Depois pressione **Enter**.

Isso é muito comum no fluxo de trabalho de quem utiliza AutoCAD com frequência, pois reduz a necessidade de procurar ferramentas nos menus.

### Exemplo prático

Imagine que você queira desenhar uma parede com **4 metros de comprimento**.

Você pode iniciar o comando:

```text
L
```

Pressione **Enter**, escolha o ponto inicial e informe:

```text
@4,0
```

Pressione **Enter**.

O AutoCAD criará uma linha horizontal com 4 unidades de comprimento.

> **Dica:** aprender a trabalhar com coordenadas é uma das melhores formas de desenvolver precisão no AutoCAD. Em vez de depender apenas do mouse, você começa a controlar exatamente onde cada elemento será criado.

### Quando utilizar o LINE?

O comando pode ser utilizado para:

- Criar paredes e divisórias;
- Fazer linhas de construção;
- Criar detalhes técnicos;
- Definir limites de objetos;
- Construir desenhos geométricos;
- Criar elementos de plantas e projetos.

Para quem está começando, dominar o **LINE** é importante porque muitos outros comandos e técnicas do AutoCAD dependem de elementos criados inicialmente com linhas.

## 2. POLYLINE — Criar linhas conectadas

O **POLYLINE**, também conhecido como **PLINE**, permite criar uma sequência de segmentos conectados que funciona como um único objeto.

Isso faz uma grande diferença em determinadas situações.

Por exemplo, imagine o contorno de uma parede ou de uma área de uma planta. Com várias linhas independentes, cada segmento pode precisar ser selecionado individualmente. Com uma polilinha, todo o conjunto pode funcionar como um único objeto.

Para iniciar:

```text
PLINE
```

Ou simplesmente:

```text
PL
```

Depois pressione **Enter**.

Clique nos pontos desejados para criar os segmentos.

### LINE x POLYLINE: qual a diferença?

Essa é uma dúvida bastante comum entre iniciantes.

**LINE:** cada segmento é um objeto separado.

**POLYLINE:** vários segmentos conectados podem formar um único objeto.

Essa diferença se torna especialmente importante em desenhos que possuem **contornos, áreas fechadas e geometrias mais complexas**.

> **Dica de iniciante:** não tente apenas decorar os comandos. Procure entender por que determinado comando é mais adequado para cada situação. Isso fará você evoluir muito mais rápido.

## 3. CIRCLE — Criar círculos

O comando **CIRCLE** permite criar círculos utilizando diferentes métodos.

A forma mais simples é definir:

1. O centro;
2. O raio.

Digite:

```text
CIRCLE
```

Ou utilize o atalho:

```text
C
```

Pressione **Enter**, escolha o centro do círculo e informe o raio.

Por exemplo, para criar um círculo com raio de 50 unidades, você pode informar:

```text
50
```

O comando é bastante utilizado em desenhos técnicos para representar:

- Furos;
- Pilares;
- Tubulações;
- Componentes mecânicos;
- Elementos circulares de plantas;
- Detalhes arquitetônicos.

## 4. RECTANGLE — Criar retângulos

O comando **RECTANGLE** permite criar retângulos rapidamente.

Digite:

```text
RECTANG
```

Ou:

```text
REC
```

Depois pressione **Enter**.

Clique no primeiro ponto e, em seguida, informe o segundo ponto.

Uma das vantagens desse comando é que você pode definir rapidamente as dimensões do retângulo, tornando-o bastante útil para representar ambientes, objetos e elementos geométricos.

## Uma dica importante para quem está começando no AutoCAD

Aprender esses comandos individualmente é apenas o primeiro passo.

O verdadeiro ganho de produtividade acontece quando você começa a **combinar os comandos**.

Por exemplo, imagine uma situação em que você precisa criar uma parede:

**LINE → OFFSET → TRIM**

Você pode criar uma linha, utilizar o **OFFSET** para gerar uma segunda linha paralela e depois utilizar o **TRIM** para ajustar os encontros.

É dessa maneira que o AutoCAD começa a ficar muito mais rápido e intuitivo.

Por isso, não se preocupe em decorar dezenas de comandos de uma vez. Comece pelos mais utilizados, pratique e, aos poucos, amplie seu repertório.
