# Comandos do AutoCAD que Todo Iniciante Precisa Conhecer

Se você está começando a aprender AutoCAD, provavelmente já percebeu que existem dezenas de comandos, ferramentas e atalhos diferentes.

No início, pode parecer difícil saber por onde começar. A boa notícia é que você **não precisa decorar todos os comandos do AutoCAD para começar a criar seus primeiros projetos**.

Existem alguns comandos fundamentais que aparecem constantemente em desenhos técnicos, plantas baixas, projetos arquitetônicos e diversos outros trabalhos.

Neste guia, você vai conhecer os principais **comandos do AutoCAD para iniciantes**, entender para que cada um serve e descobrir como utilizá-los no dia a dia.

## Quais comandos do AutoCAD um iniciante deve aprender primeiro?

Para começar, vale concentrar seus estudos nos comandos que permitem:

- Criar linhas e objetos;
- Modificar desenhos;
- Copiar elementos;
- Criar formas geométricas;
- Ajustar medidas;
- Organizar o projeto;
- Trabalhar com precisão;
- Criar desenhos mais rapidamente.

Entre os comandos mais importantes estão:

1. LINE
2. POLYLINE
3. CIRCLE
4. RECTANGLE
5. OFFSET
6. TRIM
7. EXTEND
8. MOVE
9. COPY
10. ROTATE
11. MIRROR
12. FILLET
13. ERASE
14. DIM
15. HATCH
16. LAYER

A seguir, vamos entender cada um deles.

## 1. LINE — Criar linhas

O comando **LINE** é um dos primeiros comandos que você deve aprender no AutoCAD.

Ele permite criar linhas entre dois pontos determinados.

Para utilizar:

```text
LINE
```
