# Como Colocar Cotas no AutoCAD: Guia Passo a Passo para Iniciantes

Saber **como colocar cotas no AutoCAD** é fundamental para quem deseja criar desenhos técnicos, plantas arquitetônicas e projetos com medidas precisas.

As cotas permitem informar ao leitor exatamente qual é o tamanho de determinado elemento do desenho.

Uma parede pode ter 3 metros, uma porta pode ter 80 centímetros e uma janela pode possuir 1,20 metro de largura. Essas informações precisam aparecer de maneira clara no projeto.

Neste guia, você vai aprender como colocar cotas no AutoCAD, quais comandos utilizar, como configurar o estilo das dimensões e quais erros evitar.

## O que são cotas no AutoCAD?

As cotas são elementos utilizados para representar medidas dentro de um desenho técnico.

Elas podem indicar:

- Distâncias;
- Comprimentos;
- Larguras;
- Alturas;
- Raios;
- Diâmetros;
- Ângulos;
- Distâncias entre elementos.

Por exemplo, em uma planta baixa, uma cota pode indicar que determinada parede possui:

```text
3,50 m
```
