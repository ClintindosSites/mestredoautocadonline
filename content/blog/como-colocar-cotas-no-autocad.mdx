## Como Colocar Cotas no AutoCAD: Guia Passo a Passo

Saber **como colocar cotas no AutoCAD** é essencial para criar plantas, desenhos técnicos e projetos com medidas claras e precisas.

Neste guia, você vai aprender a inserir cotas, medir distâncias e configurar as dimensões para deixar seu desenho mais organizado.

## O que são cotas no AutoCAD?

As cotas são elementos usados para **informar medidas dentro de um desenho técnico**.

Elas podem representar:

- Comprimentos;
- Larguras;
- Alturas;
- Distâncias;
- Raios;
- Diâmetros;
- Ângulos.

Em uma planta baixa, por exemplo, uma cota pode mostrar que determinada parede possui **3,50 m**.

Além de facilitar a interpretação do projeto, as cotas são fundamentais para transformar um desenho em uma representação técnica realmente útil.

## Como colocar uma cota no AutoCAD?

O AutoCAD possui diferentes ferramentas para criar dimensões. A mais utilizada para medir linhas e distâncias horizontais ou verticais é o comando **DIM**.

### Passo 1 — Ative o comando de cota

Na linha de comando do AutoCAD, digite:

```text
DIM
```

Depois, pressione **Enter**.

Você também pode acessar a ferramenta de dimensionamento pela faixa de opções do programa.

### Passo 2 — Selecione os pontos

Clique no primeiro ponto da medida e depois no segundo.

O AutoCAD calculará automaticamente a distância entre eles.

### Passo 3 — Posicione a cota

Mova o cursor para definir onde a dimensão ficará posicionada e clique novamente.

Pronto. A medida será adicionada ao desenho.

> **Dica:** mantenha as cotas afastadas das linhas do desenho sempre que possível. Isso facilita bastante a leitura do projeto.

## Principais tipos de cotas no AutoCAD

Dependendo do elemento que você precisa medir, diferentes tipos de dimensionamento podem ser utilizados.

### Cota linear

Utilizada para medir distâncias horizontais ou verticais.

É muito comum em:

- Plantas baixas;
- Projetos arquitetônicos;
- Desenhos de móveis;
- Projetos mecânicos.

### Cota alinhada

Acompanha a inclinação do objeto que está sendo medido.

É especialmente útil para elementos diagonais.

### Cota angular

Indica o ângulo entre duas linhas ou elementos.

### Cota de raio

Utilizada para indicar o raio de círculos e arcos.

### Cota de diâmetro

Indica o diâmetro de um círculo.

## Como deixar as cotas mais profissionais?

Não basta simplesmente colocar as medidas. Em um projeto profissional, a apresentação também importa.

O AutoCAD permite configurar o **estilo das cotas**, alterando elementos como:

- Tamanho do texto;
- Setas;
- Casas decimais;
- Escala;
- Espaçamento;
- Unidades;
- Posicionamento das informações.

Para acessar essas configurações, utilize o comando:

```text
DIMSTYLE
```

Esse comando abre o gerenciador de estilos de cotas.

A partir dele, você pode criar ou modificar um padrão para utilizar em todo o projeto.

## Um erro comum de quem está começando

Um dos problemas mais comuns é colocar as cotas sem pensar na organização do desenho.

Quando existem muitas dimensões sobrepostas, textos pequenos ou medidas espalhadas sem padrão, o projeto fica difícil de interpretar.

Por isso, procure manter:

- Espaçamento consistente;
- Textos legíveis;
- Cotas alinhadas;
- Unidades padronizadas;
- Informações organizadas por níveis.

Pequenos ajustes de organização já fazem uma grande diferença no resultado final.
